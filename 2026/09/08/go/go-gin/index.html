web_project

项目简介

web_project 是一个结构清晰、易于扩展的 Gin 脚手架，当前已集成以下能力：

  • 使用 Viper 统一管理配置文件，并支持配置热更新
  • 使用 Zap + Lumberjack 实现结构化日志输出与日志文件切割
  • 使用 GORM + MySQL 完成数据库初始化与连接池配置
  • 使用 go-redis 完成 Redis 初始化与可用性探测
  • 使用 Gin 注册路由、接入访问日志和 panic 恢复中间件
  • 使用 net/http + signal 实现服务优雅退出

扩展建议

项目当前仅提供基础脚手架能力，可以根据业务需要按以下方式扩展：

  • 在 apis/ 中新增 HTTP 处理函数
  • 在 router/router.go 中注册路由
  • 在 logic/ 中编写业务逻辑
  • 在 models/ 中定义数据库模型
  • 在 dao/ 中封装数据访问操作
  • 在 pkg/ 中沉淀通用工具代码
